# 验证管理

6个基础任务，每任务6对，共36对核心样例；4任务开发、2任务保留。另有约8—10对边界测试。详见项目草案。

样例清单建议字段：pair_id、task_id、split、label、modification、source_file、target_file、source_ranges、target_ranges、notes。字符与词法单元的细粒度标注规则待实现阶段确定。

先固定分组，再看结果。同一任务的全部变体同组。保留材料放 holdout-local/，不提交、不纳入常规CI。独立答案需注明实际来源，不将改写版本冒充独立完成。

所有实验记录代码提交、参数、任务分组、三状态结果与定位表现。当前未构造样例、未进行评估，任何性能数值均未产生。
