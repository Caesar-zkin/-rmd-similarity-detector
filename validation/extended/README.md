# 加长开发材料：单独记录的派生控制

原有20对基础材料很短，development-v1全部返回证据不足。本组补充较完整的分析段落、推导和代码，观察既有方法在内容增多后的行为；不修改算法或默认门槛。
这些材料仍由项目自建，不能声称代表真实班级作业。所有目标文件明确由源文件派生，不是独立作答，不是保留集，也不是学术抄袭判定的权威真值。

## 先确定材料，再观察结果

设计要求是内容完整、有统计含义、修改来源可核查，不按某个目标判定结果筛选样例：

| 家族 | 内容与变换 |
|---|---|
| E01 文字 | 三段分析：数据质量、中心位置、离散与推断范围；轻改每段少量措辞，局部版仅保留中间一段 |
| E02 公式 | 平方距离和展开、求导、令导数为零、求最优中心，共五步；轻改一致替换x/c并插入Q(0)，局部版只保留末三步 |
| E03 代码 | 固定八个观测值，十二条顶层语句计算均值、样本方差、标准差和均值标准误；轻改变量名并插入打印，局部版只保留前六句 |

每个家族都有exact、format、light_edit、local四种变换，共12对，但只有3个源家族，不是12次独立抽样。没有额外合成负例冒充真人独立答案。
局部版没有义务达到当前强证据门槛，轻改版也不预设必须触发疑似。保留实际结果，不能通过修改材料或降低门槛追求全部命中。
E02推导与E03代码使用常见统计方法；即使复制来源已知，也不能据此断定同样推导或常规代码在真实作业中必然构成抄袭。这类正常相似仍须依靠独立答案和明确公共来源进行验证。

三组材料与原来六个固定任务的36名额分开登记，原始短样例、任务分组、独立名额和保留名额均不变。本组是开发补充控制，不作为新的保留任务，不补足独立答案名额。
题目说明不作为公共题干放入两侧正文；YAML标题和章节标题由原解析流程排除。程序不执行代码、不计算样本统计量，也不使用输入文件的YAML指令。

## 文件与来源标注

- cases.csv：12对材料的家族、类型、变换、显式路径和自建来源说明。
- fixtures/E01—E03/base.Rmd：源材料；同目录其余四份为派生目标。
- annotations.csv：140条两侧来源范围和quote，按规范化后source的1基字符位置，包含两端。

来源范围表达复制来源，轻改后的不同字符也可在来源标注内。插入的Q(0)和额外打印不标注为复制内容；局部版只标注源文件实际复用的部分。
公式标注逐行记录，代码逐语句记录；所有标注必须位于对应类型的一个解析单元中，不允许重叠，quote必须与原文精确一致。
定位评价沿用现有定义：文字相同字符、局部代码token、公式序列步骤分开计数。文字改写字符不算相同字符，公式与代码也不换算为字符覆盖。

## 运行与结果

在仓库根目录的PowerShell终端运行：

```powershell
$projectRscript = "C:\Program Files\R\R-4.6.1\bin\Rscript.exe"
& $projectRscript tests/test-extended-validation.R
& $projectRscript scripts/run-extended-validation.R
Import-Csv .\reports-local\extended\results.csv |
    Format-Table pair_id,candidate_verdict,candidate_pathway
```

输出到已忽略的reports-local/extended/，重复运行覆盖同名文件：

- results.csv：逐对开发候选、路径、状态、错误、双向文字/代码覆盖以及各类型最大真实匹配长度。
- localization.csv：每对两侧各三种方法的复制来源定位指标，失败不当作零覆盖。
- decision-summary.csv：描述本组候选三状态的数量和比例；无独立答案，false_alarm_rate为NA。
- input-and-code-hashes.csv：显式输入、清单、标注、运行代码和检测模块指纹。
- experiment.rds：完整结果、实际参数、清单、R/sessionInfo、时间和可取得的Git提交。

largest_text_match、largest_math_match、largest_code_match分别是证据组代表记录的字符数、步骤数、token数，不能相加或解释成统一分数。证据整理失败时为NA，成功但没有该类证据时为0；同时查看模块状态。
开发比例只描述这12个派生控制，不与基础20对、边界10对合成总体准确率；不报告置信区间、泛化效果或真实误报估计。正式verdict保持not_enabled。
测试核对来源、隔离、默认参数、排版不变性和快照，不锁定候选疑似数量。实际观测由CSV和RDS记录，后续结果复核不能反过来当作独立验证。

本入口仅读取extended/fixtures下登记的文件，拒绝目录穿越和跨家族错配，不扫描独立答案或保留目录。尚无真实独立答案，保留组仍未采集、未运行，参数仍未冻结。
