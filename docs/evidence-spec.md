# 既有证据整理与去重

## 范围冻结
后续只完成既定交付：证据整合、综合判定、必要验证、报告与交付整理。不扩展新的检测方法、语法支持或界面。
本模块仅整理现有五接口结果，不改变匹配算法、默认门槛或公共来源排除规则。

## 统一记录
每条已有匹配生成record_id，记录kind/unit、原模块、原表、source_row、方法、层次、实际位置、有效长度、相似指标和原文行号。
module/table/source_row定位到原分析结果，原始变量映射、跳步、对齐及参数仍以原表为准，不重建或改写。
文字位置只取真正相同字符；代码位置取对应token起点；公式位置取受支持推导步骤ID。三种单位不相加，相似指标也不跨方法平均。

完整公式对照与步骤对照使用同一父单元派生的步骤ID，避免把同一公式重复计数。完整代码与局部代码使用相同token起点。
只有原文相同、但语法/词法未支持的比较保留为辅助记录，eligible=false，不提供有效位置、有效长度或位置分组。注释等原有补充信息仍在原模块，不作为独立主要证据累计。
短常规调用和短标准公式仍可以有有效位置，但不因此触发疑似；长度和支持条件由下一阶段综合规则约束。

## 保守位置分组
同类记录在A或B任意一侧共享至少一个实际位置，即通过连接关系归入同组。两个侧面都不重叠的组保持分开。
这样同一源片段匹配目标多个位置时，不会被计成多处互不重叠来源。通过重叠链形成的大组也保守处理，可能降低累计证据数量。
字符范围外包、行号外包及未匹配的插入/替换位置不参与连接。排除前baseline不进入整理，只有当前modules参与。

groups保留组中方法来源、代表record_id、真实代表长度largest_match、代表内容token量、两侧位置并集数量和展示行号。
largest_match取真实记录长度，不把多个片段拼成长匹配。unique_a/b只用于核对实际位置并集，不表示存在该长度的一次对应。
分组不是统计独立性证明，也不保证组内所有记录共享同一变量映射、顺序或一一对应。候选规则应选择真实记录并检查其原始支持，不能合并映射。

## 接口与失败
summarize_pair_evidence(result)返回records/groups/issues；group_position_evidence(records)实现分组并检查位置与资源上限。
默认最多100000条记录和5000000个两侧位置引用，超限明确报错，不截断后声称结果完整。主要结果来自现有模块。
analyze_rmd_pair的evidence沿用模块状态包装：status/error/warnings/value。输入或排除配置无效时not_run；整理失败时整体partial_failure，原模块结果仍可核查。
原模块分析受限或缺步骤视图时保留limited和issues。未知内容不会因此被宣布已完成分析。

## 报告与验收
报告新增“证据整理：位置重叠与方法来源”，展示位置分组及原记录索引，各最多100行，完整结果保留在返回对象。
保持原分项表和覆盖率，避免仅凭整理表丢失定位细节。当前verdict仍not_enabled。
tests/test-evidence.R检查重复方法、单侧重叠、重叠链、分离位置、单位隔离、辅助原文记录、有效长度、原结果引用、资源错误及排除后的范围。
没有新增检测能力，没有生成准确率或综合判断。后续只接既定三状态规则、验证和交付。
