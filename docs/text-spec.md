# 文字模块规格

## 当前功能

extract_text_units(doc) 从解析结果中提取正文单元。

输入必须是解析器返回的 rmd_document 对象。

输出保留 type 为 text、status 为 ok 的全部行，
并保留原文、位置及上下文字段。

没有正文时，返回保留列结构的零行数据框。
输入类型不符合要求时，明确报错。

## 当前范围

已完成正文提取、基础空白规范化、文档级字符位置映射、
字符片段生成、整体Jaccard相似度及相同片段定位。

尚未实现Markdown排版处理、候选单元筛选、
连续匹配合并、近似局部对齐、覆盖率及最终判定。

## 文字规范化

normalize_text(text) 接收单个非缺失字符串，返回：

- text：去除支持的空白字符后的文字。
- source_positions：每个输出字符在输入字符串中的1基字符位置。

支持普通空格、制表符、换行、回车、换页、垂直制表符、
不换行空格及全角空格。

保留大小写、标点及其他字符。
空字符串或全空白输入返回空字符串和空整数位置向量。
非字符、缺失值及多个字符串输入会报错。

当前位置映射相对于输入字符串，尚未连接整篇文档位置。
Markdown排版符号处理尚未实现。

## 文档级文字准备

prepare_text_units(doc) 提取并规范化正文单元。

输出保留原单元字段，并增加：
- normalized_text：规范化后的文字。
- source_positions：每个规范化字符在 doc$source 中的1基字符位置。

换算使用内容起点 content_start，而非原文单元起点。
各单元分别保留，不跨公式或代码拼接。
没有正文时返回保留列结构的零行数据框。

位置对应解析器统一换行后的 source，不是磁盘字节位置。

## 连续字符片段

make_character_ngrams(text, k = 5L) 按字符生成连续片段，
相邻片段起点相差1。

返回数据框：
- gram：片段文字。
- start：片段在输入字符串中的1基起点。
- end：片段在输入字符串中的1基终点，包含该字符。

输入短于k时返回列结构一致的零行数据框。
重复片段保留各自的位置。
k必须为可表示的正整数。

本函数不自动规范化文本；调用方应传入规范化后的字符串。
默认k仅为初始设置，尚未验证其检测效果。

## 文档级片段生成

make_document_ngrams(doc, k = 5L) 对每个正文单元分别生成片段。

返回字段：
- file_id、unit_id、context_id：文件、单元及上下文标识。
- gram：片段文字。
- normalized_start、normalized_end：在本单元规范化文字中的位置。
- source_positions：片段各字符在 doc$source 中的位置。

不跨正文单元生成片段，保留重复片段的不同出现位置。
无正文或全部单元过短时，返回列结构一致的零行数据框。
即使没有正文，也验证k是否合法。

source_positions可能不连续。
后续计算覆盖率应使用实际字符位置，不能将间隔全部计入。

## 正文Jaccard相似度

compare_text_jaccard(doc_a, doc_b, k = 5L)
比较两份文档已提取正文的不重复字符片段集合。

similarity为交集大小除以并集大小。
同时返回两侧集合大小、交集大小、并集大小和k。

两侧集合均非空时，status为ok。
任意一侧无法生成片段时，similarity为NA，
status为insufficient_ngrams。

本指标不考虑片段重复次数或整体顺序。
仅比较已成功提取的正文，不代表全部文档内容均被分析。
相似度不解释为抄袭概率，也不直接用于最终抄袭判定。

## 相同字符片段定位

match_text_ngrams(doc_a, doc_b, k = 5L, max_pairs = 50000L)
按gram完全相等连接两份文档的片段表。

返回两侧文件、单元、上下文、规范化位置和原文字符位置；
两侧同名字段分别添加_a、_b后缀。

重复片段保留所有出现位置组合。
无匹配时返回列结构一致的零行数据框。

匹配对超过max_pairs时明确报错，不静默截断。
该上限用于控制运行规模，不是判定阈值。

结果仅为短片段候选匹配，尚未合并为较长匹配，
也不直接触发抄袭判定。
