# 文字模块规格

## 当前功能

extract_text_units(doc) 从解析结果中提取正文单元。

输入必须是解析器返回的 rmd_document 对象。

输出保留 type 为 text、status 为 ok 的全部行，
并保留原文、位置及上下文字段。

没有正文时，返回保留列结构的零行数据框。
输入类型不符合要求时，明确报错。

## 当前范围

已完成正文提取、基础空白规范化及文档级字符位置映射。
尚未实现Markdown排版处理、字符片段、
相似度计算、局部匹配及覆盖率。

## 文字规范化

normalize_text(text) 接收单个非缺失字符串，返回：

- text：去除支持的空白字符后的文字。
- source_positions：每个输出字符在输入字符串中的1基字符位置。

支持普通空格、制表符、换行、回车、换页、垂直制表符、
不换行空格及全角空格。

保留大小写、标点及其他字符。
空字符串或全空白输入返回空字符串和空整数位置向量。
非字符、缺失值及多个字符串输入会报错。

当前位置映射相对于输入字符串，尚未连接整篇文档位置。
Markdown排版符号处理尚未实现。

## 文档级文字准备

prepare_text_units(doc) 提取并规范化正文单元。

输出保留原单元字段，并增加：
- normalized_text：规范化后的文字。
- source_positions：每个规范化字符在 doc$source 中的1基字符位置。

换算使用内容起点 content_start，而非原文单元起点。
各单元分别保留，不跨公式或代码拼接。
没有正文时返回保留列结构的零行数据框。

位置对应解析器统一换行后的 source，不是磁盘字节位置。
