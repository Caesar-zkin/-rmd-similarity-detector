# 使用与交付说明

## 交付内容

- detector.Rmd：包含检测函数的主入口。
- 本说明：运行步骤、报告解读和功能限制。
- 两份有权使用的自建示例：用于演示输入格式。

正常检测不依赖项目的 R/ 目录。
开发时修改模块或模板，再使用构建脚本生成 detector.Rmd。

## 环境准备

提前安装 R、rmarkdown 和 Pandoc。交互页面还需要 shiny。
使用 RStudio 时，可使用其自带的 Pandoc。
检测期间不自动安装依赖，不需要 LaTeX。

## 在页面中比较

在 RStudio 打开 detector.Rmd，点击 **Run Document**。在页面中选择两份 UTF-8 编码的 Rmd，点击 **开始分析**，即可在同一页查看候选结论和证据。交互页面由本机 R 会话提供。

## 导出静态 HTML

在 R 控制台指定输入文件并编译。路径相对于 detector.Rmd 所在目录，也可使用绝对路径。

```r
rmarkdown::render("detector.Rmd", runtime = "static",
  params = list(input_a = "A.Rmd", input_b = "B.Rmd"))
```

程序只编译 detector.Rmd。
待检测作业只作为文本读取，其中的代码不会执行。

## 报告解读

报告分别展示文字、公式和代码匹配，以及原始行号。

- completed：本次分析流程完成，仍需结合各模块说明解读。
- limited：存在超出支持范围的内容，不能解释为零相似度。
- error 或 partial_failure：存在输入或模块错误，需要检查诊断。

开发候选结论包括疑似抄袭、未检出明显证据和证据不足。
规则尚未完成效果标定，正式判定未启用。
相似度和覆盖率不是抄袭概率。

## 当前限制

文字比较不保证识别语义改写。
公式比较仅支持有限的 LaTeX 结构，不证明数学等价。
代码比较支持有限的一致改名和顶层语句匹配。
公共题干、标准解法等共同来源需要人工核查。

已有自动测试、自建控制材料及 AI 样本探索记录。
真实独立作答和保留集验证尚未完成，
目前不能据此报告可靠的检测准确率。

## 本地文件管理

待检测作业和生成报告可能包含个人信息。
保存在本地，不提交到公开仓库。
