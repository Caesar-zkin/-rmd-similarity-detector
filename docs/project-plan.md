# 项目草案 V3.0：实现前基准

状态：需求与方法框架已确认；算法尚未实现；所有候选参数均未验证。
方案版本 V3.0 与软件版本 v0.x 分别维护。修改本文件时同步记录 decisions.md。

## 1. 背景与目标

课程要求用 R Markdown 完成任务：检查两份作业是否存在抄袭。教师不提供测试集，将输入未知 Rmd 作业评价检测能力。材料主要包含文字、数学公式和代码，没有统一模板或示例。

开发 detector.Rmd：接收两份 Rmd 文件，在本地生成可解释的检测报告，均衡控制漏检与误报。检测结果提供核查依据，不能证明复制方向，也不把相似度当成抄袭概率。

## 2. 输入、运行与交付

- 两个文件路径在入口集中设置。
- 编译 detector.Rmd，输出 HTML。
- 集中配置证据展示数量和可选题干排除设置。
- 判定参数使用验证后的默认值，并写入报告。
- 依赖预先安装，运行时不自动联网安装。
- 不调用外部 AI，不上传文件，不执行待检测代码。
- 检测不依赖学生作业引用的数据或软件包。
- 开发允许 R/ 模块化，最终生成单文件 detector.Rmd，避免双份手工维护。
- 配套交付示例、使用说明与验证材料。文件名、中文路径和编码策略需测试。
- HTML 离线可查看；数学内容不得隐式依赖在线排版资源。

## 3. 内容解析

先识别代码区域，再处理公式及正文。每个单元保留文件标识、类型、原始内容、比较版本、起止行号、顺序及可识别的章节。

| 类型 | 处理 |
|---|---|
| YAML 作者、日期、输出设置 | 排除主体检测 |
| 标题、题号 | 定位与组织，不作主要证据 |
| 正文、列表、表格文字 | 文字模块 |
| 行内与独立公式 | 公式模块，关联原段落 |
| R代码块、行内R代码 | 代码模块 |
| 普通行内代码标记 | 区分对象名与可执行行内代码 |
| 注释 | 单独比较，关联代码 |
| 图片、外部引用 | 记录未覆盖内容，不假定已识别其实际内容 |

明确标记的题干可单独统计并展示处理前后结果。标题不自动意味着其后均为题干。无法可靠区分时保留并提示。不能把两份共同内容直接删除。可选题目文件或手动排除区间不应成为基本运行前提。

缺少某类内容标“不适用”；存在但解析失败标“分析受限”。异常不能直接计为零相似度。

## 4. 文字模块

- 段落为基本单元，长段使用重叠窗口，并允许跨位置匹配。
- 统一空白与排版标记；保留原文及位置映射。
- 以字符片段重合筛选候选，再进行局部顺序比较，核查插入、删除和替换。
- 输出全文字符片段 Jaccard、有效局部片段及双向覆盖率。
- Jaccard 为共有片段集合大小除以片段集合并集大小；空集合情况须明确定义。
- 文字层面支持原样复制、少量修改、局部复制；不承诺大幅语义改写识别。
- 短常见表达不单独形成主要证据；匹配需达到有效长度与相似程度要求。
- 仅凭两份文档不能可靠估计表达是否罕见，不能自动声称匹配内容“独特”。

## 5. 公式模块

三层比较：原始表达、排版规范化、一致符号改名后的结构。

- 识别公式后统一定界符、排版空白及明确支持的命令。
- 可统一 frac/dfrac/tfrac 和间距、定界大小命令，保留实际括号。
- 简单上下标仅在解析明确时规范。
- 保留数字、运算符、正负号、上下标、字体语义命令及 text 中的说明。
- 变量映射一一对应，保持重复引用关系；连续推导中也保持一致。
- 保留函数名及数学结构。x+x 与 a+b 不能视为相同改名结构。
- 比较单条与相邻多步推导；多行环境尽量提取步骤。
- 允许跨位置寻找序列匹配及少量步骤插删。
- 单个简短标准公式及仅规范化后结构一致，不单独触发疑似。
- 足够长的推导可以形成主要证据；结合附近文字增加解释依据。
- 不进行一般数学等价性证明，不声称自动识别所有标准公式或错误。
- 未支持的 LaTeX 命令、宏及解析失败明确提示。

## 6. 代码模块

三层比较：原始文本、忽略排版的词法单元、一致变量规范化。

- 保留函数名、参数名、运算符、控制结构、数字和字符串。
- 可可靠识别的用户变量按一致映射规范化。
- 数据列名与成员名基本版保留；复杂作用域、自定义函数等无法可靠识别时保留原名。
- 代码块为基本单位，长块按词法单元分重叠窗口。
- 保留操作顺序，允许少量插删替换与跨位置匹配。
- 映射覆盖整个候选片段，不能逐行重新映射。
- 注释另作补充，短常见注释权重有限；与正文重复的解释不能重复当作独立证据。
- 重点支持 R；其他语言做有限文本比较并标明能力范围。
- 不执行代码；语法不完整时尽可能保留文本比较并提示。
- 不专门识别循环改为向量化等大幅逻辑重构。
- 短常规统计调用及仅规范化后的短结构不单独触发疑似。

## 7. 证据、定位和覆盖

每项匹配记录类型、两侧位置、方式、相似程度、有效长度与上下文支持。

- 重叠窗口和同一片段多层匹配合并，不能累计成独立证据。
- 覆盖率只计算实际对齐位置的并集，不将整个候选窗口计入。
- 对A和B分别计算覆盖内容量/有效内容总量。
- 同时关注整篇和局部。某一题被复制时，不因全篇占比较低而忽略。
- 题目边界不明确时退回段落或片段层面。
- 覆盖表示包含程度，不推断复制方向。
- 各类有效长度分别定义，不能直接把字符数与词法单元数相加。

## 8. 综合判断

三状态：疑似抄袭、未检出明显证据、证据不足。

两条触发路径：
1. 单处较强匹配：达到较严格的有效长度、相似程度及支持条件。
2. 多处累计匹配：多个不重叠达标片段累计满足有效长度与覆盖要求。

某一类可以独立提供主要证据，不要求三类都高，不取简单平均。仅高度规范化后匹配的内容要求更多支持。短句、单个简单公式、短常规代码不单独触发。无法区分公共来源时标注不确定性。

暂不合成总相似度或抄袭概率。阈值待验证；若评分要求二元接口，另行明确证据不足的处理方式。

## 9. 自建测试材料

6个基础任务：文字2、数学推导2、代码与解释混合2。
每个任务6对：原样复制、格式修改、轻度修改、局部复制、分散复制、同题独立作答，共36对核心样例。

每类任务1个进入开发集，另1个的分配需满足开发4、保留2；分配规则在查看保留结果前确定。整体覆盖三类内容，保留测试的代表性局限如实说明。

- 按基础任务分组，4任务开发、2任务保留。
- 同一原作业全部变体不跨组，相关样例不当作独立实验。
- 记录复制源位置、目标位置与修改方式。
- 独立作答尽量由不同成员独立完成，不能用大幅改写代替。
- 另有约8—10对边界样例：空文件、仅YAML、缺少某类内容、中文路径、不完整语法、共同题干、短常规内容及长文局部复制。
- 边界测试独立报告，不混入总检测成绩。
- 保留材料不用于调参、日常测试或常规CI。若据其修改规则，该批材料转为开发，需新的保留样例。

## 10. 起始参数候选

| 参数 | 候选 |
|---|---|
| 字符片段长度 | 3、5、7 |
| 长文字窗口 | 100、200字符 |
| 窗口重叠 | 初始50% |
| 文字局部相似门槛 | 0.75、0.85、0.95 |
| 文字最低匹配长度 | 30、60、100字符 |
| 长代码窗口 | 50、100词法单元 |
| 代码最低匹配长度 | 20、40、60词法单元 |
| 代码局部相似门槛 | 0.80、0.90、0.95 |
| 公式范围 | 单条及相邻2—5步 |

全部未验证。短内容整体比较；不组合不可能的长度条件。公式有效长度、候选筛选门槛、综合长度与覆盖阈值待开发阶段明确。

先检验解析，再局部检测，再综合阈值；不一次穷举所有参数。开发集按基础任务轮流留出验证，规则冻结后才运行保留集。

## 11. 评价

报告混淆情况、精确率、召回率、误报率、F1、有效判定比例与定位表现。指标分母与零分母情况明确说明。

三状态主选择分数：
S = 0.5 × [复制样例判为疑似数/全部复制样例数 + 独立样例判为未检出数/全部独立样例数]。

证据不足保留在分母，并分别报告其真实类别，避免通过弃判提高成绩。无弃判时该分数等于二分类平衡准确率；有弃判时命名为“含弃判惩罚的均衡正确率”，不混用通常二分类定义。

候选相近时优先简单、跨任务稳定的规则。两者均衡不等于两种错误率必须相等。精确率受人为样例比例影响，不能直接外推课堂。

## 12. 报告与运行检查

报告顺序：综合判断、文件与解析概况、分项结果、片段对照与行号、参数规则、方法验证及局限。

输入内容安全转义后展示；不可执行 HTML 或待检测代码。文件不存在、编码问题、内容过短、解析失败要明确提示。不暗示未分析内容已经得到比较。

## 13. 阶段与验收

读取解析 → 文字 → 公式 → 代码 → 证据合并与报告 → 开发验证 → 冻结规则与保留测试 → 交付。

- 从头编译成功；异常输入合理提示。
- 有效原样复制样例全部识别。
- 定位对应已知复制区间。
- 证据不重复统计。
- 常见短内容不单独触发。
- 完整披露失败样例，不预先承诺百分比性能。

## 14. 局限与待实现规格

无法仅凭相似度证明抄袭或方向；共同题干和标准解法可能造成歧义。深度改写、图片、复杂宏、复杂作用域及算法重构不保证识别。

实现前逐模块明确：解析输出字段、支持的语法子集、局部顺序比较公式、有效长度定义、缺失处理、证据合并规则。上述细节不视为已验证能力；实质变更须记录。
