# 路线图

软件版本与方案版本分别维护。下面是计划，不表示功能已完成。

| 版本 | 范围 | 验收 |
|---|---|---|
| v0.1.0 | 方案与仓库初始化 | 文档和目录完整 |
| v0.2.0 | 读取、解析、行号定位 | 小样例分类正确；异常处理明确 |
| v0.3.0 | 文字模块 | 原样、轻改、局部匹配可定位 |
| v0.4.0 | 公式模块 | 支持的排版规范及一致映射有验证 |
| v0.5.0 | R代码模块 | 词法和改名匹配；有限降级提示 |
| v0.6.0 | 合并证据、判断、HTML报告 | 覆盖不重复；内容安全展示 |
| v1.0.0 | 验证、冻结、单文件交付 | 完整公开保留测试结果和局限 |

## 当前阶段：v0.3.0文字模块开发
解析器已合入main。文字模块在feat/text、PR #2开发。
已实现正文规范化、文档位置映射、片段集合Jaccard、连续精确匹配和去重双向覆盖率。可运行examples/run-text-demo.R。
