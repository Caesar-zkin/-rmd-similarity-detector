# 结构测试

从仓库根目录运行：

```sh
Rscript tests/test-parser.R
```

无需额外R包。测试覆盖原文重建、定位、分类、未闭合标记、中文路径、编码和不执行代码。GitHub Actions在Linux/Windows执行同一脚本；本地环境无R时以实际CI结果为准，不能声称本地测试通过。

这些是自建结构用例，不是36对性能样例；不包含保留集，不用于证明检测准确率。


## 连续匹配与覆盖测试

运行 `Rscript tests/test-text-matches.R`。
验证合并、偏移重复、错配断开、单元边界、空白映射、缺少正文、
最低长度、行号和解析警告传播。覆盖使用字符并集，不累计重复证据。
CI在Linux和Windows运行三组测试及文件演示，不使用保留性能集。
